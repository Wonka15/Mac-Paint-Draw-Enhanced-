# Changelog

Notable changes are recorded here for users and contributors.

## [2.0.0] — 2026-10-15

### Added
- Animation Studio frame duplication, keeping copied artwork editable.
- Corvette dashboard's amber clock digits, green battery indicator, red weather temperature digits, and electrical-blue EL border shimmer.
- Beginner-oriented project map, maintenance guidance, contribution steps, and repeatable automated checks.

### Improved
- Polished the classic Macintosh toolbox controls and pressed/selected icon feedback.
- Raised the drawing board slightly in iPad landscape layout.
- Expanded automated checks to syntax-check every local JavaScript module and verify required controls, release metadata, and CSS brace balance.
- Updated the page title, visible version badge, stylesheet cache key, and repository documentation to align on version 2.0.

### Notes
- The app remains a static site hosted by GitHub Pages.
- Browser support for battery reporting and third-party radio streams varies by device/provider.
- The weather dashboard asks for location only after the user chooses **GET WEATHER**.
